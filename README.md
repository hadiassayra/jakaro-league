# دوري جاكرو 🎯

تطبيق ويب لإدارة بطولة جاكرو: من استيراد الفرق والقرعة، إلى جدول المباريات والترتيب، ثم الأدوار الإقصائية حتى تتويج البطل. يعمل على الهاتف واللابتوب وشاشة التلفاز، والواجهة كلها بالعربية (من اليمين لليسار).

---

## التشغيل

يحتاج [Node.js](https://nodejs.org) الإصدار 18 أو أحدث.

```bash
cd jakaro-league
npm install
npm run dev
```

افتح العنوان الذي يظهر (مثل `http://localhost:5173`). يظهر أيضاً **عنوان الشبكة** (مثل `http://192.168.1.31:5173`): افتحه من أي هاتف متصل بنفس شبكة الـ Wi-Fi.

| الأمر | الوظيفة |
|---|---|
| `npm run dev` | تشغيل التطبيق أثناء التطوير |
| `npm run build` | بناء نسخة جاهزة للنشر في مجلد `dist` |
| `npm run preview` | تجربة النسخة المبنية |
| `npm test` | تشغيل اختبارات منطق البطولة |

مجلد `dist` موقع ثابت يمكن رفعه إلى أي استضافة (Netlify أو Vercel أو GitHub Pages…).

> عند التشغيل لأول مرة تظهر **بطولة تجريبية من 12 فريقاً** لتجربة كل الشاشات. لبدء بطولتك: **الإعدادات ← بطولة جديدة**.

## خطوات البطولة

1. **الفرق**: أضف الفرق يدوياً أو استوردها من Excel.
2. **القرعة**: توزيع الفرق على المجموعتين أ و ب.
3. **المباريات**: «توليد الجدول»، فيُنشأ دوري كامل داخل كل مجموعة مقسّماً إلى جولات، ومع أرقام الطاولات.
4. **إدخال النتائج**: اضغط على أي مباراة، ثم اختر الفريق الفائز، ثم عدد كرات الفريق الخاسر المتبقية (0–8)، ثم «حفظ».
5. **الترتيب**: بعد انتهاء كل المباريات اضغط «اعتماد نتائج المجموعات».
6. **الإقصائيات**: «توليد الشجرة»، ويتقدّم الفائزون تلقائياً حتى النهائي.

### قواعد الترتيب
- الفوز = نقطة، والخسارة = صفر، ولا يوجد تعادل.
- **نقاط الفرق**: مجموع كرات الخصوم المتبقية عندما يفوز الفريق، **ناقص** كرات الفريق المتبقية عندما يخسر.
- الترتيب يكون بالنقاط، ثم نقاط الفرق، ثم المواجهة المباشرة، ثم **قرار المنظم** (قرعة/عملة). عند التعادل الكامل تظهر أداة لترتيب الفرق يدوياً، ويُعلَّم الفريق بشارة «🪙 يدوي».
- شارة **✓ متأهل** تعني أن الفريق تأهل رياضياً مهما كانت النتائج القادمة، وشارة **خارج** تعني أنه لم يعد قادراً على التأهل.

### الأدوار الإقصائية
- يتأهل أول 4 من كل مجموعة (يمكن تغييره إلى 1 أو 2 أو 8 من الإعدادات؛ مع 8 يبدأ دور الـ16).
- التوزيع متقاطع: أ1 × ب4، ب2 × أ3، ب1 × أ4، أ2 × ب3، فلا يلتقي متصدرا المجموعتين إلا في النهائي.
- مباراة المركز الثالث اختيارية من الإعدادات.
- إلغاء اعتماد المجموعات (بعد رسالة تأكيد) يحذف الشجرة حتى يمكن تعديل النتائج.

## استيراد الفرق من Excel

من صفحة **الفرق** اضغط «📥 استيراد من Excel» واختر ملف ‎`.xlsx` أو ‎`.csv`.

الأعمدة المطلوبة (يمكن تنزيل **القالب** الجاهز بالضغط على «⬇ القالب»):

| اسم الفريق | اللاعب 1 | اللاعب 2 | المجموعة (اختياري) |
|---|---|---|---|
| الصقور | أحمد | خالد | أ |
| النمور | محمد | سعد | B |

- عمود المجموعة يقبل `A` أو `B` أو `أ` أو `ب`.
- تظهر **معاينة** قبل الاستيراد، وتُعلَّم فيها الصفوف الفارغة والأسماء المكررة والصفوف التي ينقصها لاعب. يمكنك اختيار الصفوف التي تريد استيرادها.
- إذا لم يكن في الملف عمود مجموعة، ينقلك التطبيق إلى **القرعة**.
- يمكن تعديل أسماء الفرق واللاعبين بعد الاستيراد (✏️).

### القرعة
- «🎲 ابدأ القرعة» تُسقط الفرق واحداً تلو الآخر في المجموعتين مع حركة وصوت. «إعادة القرعة» تعيدها من جديد.
- لنقل فريق يدوياً: اسحبه وأفلته في المجموعة الأخرى، أو اضغط عليه ثم «نقل الفريق المحدد إلى هنا» (مناسب للهاتف).
- «✓ اعتماد التوزيع» يحفظ المجموعات ويولّد الجدول.

## وضع العرض (عرض النتائج) 📺

- زر **«📺 عرض النتائج»** في أعلى الصفحة يفتح وضع العرض للتلفاز أو جهاز العرض. لفتحه في نافذة مستقلة على شاشة ثانية استخدم «فتح العرض في نافذة جديدة» من الصفحة الرئيسية، ثم اسحب النافذة إلى الشاشة.
- تتبدّل الشرائح تلقائياً بهذا الترتيب: ترتيب المجموعة أ، ثم ترتيب المجموعة ب، ثم المباريات، ثم الشجرة، ثم الإحصائيات. مدة كل شريحة قابلة للتعديل من الإعدادات.
- **مفاتيح التحكم:** `←` للتالي، `→` للسابق، `مسافة` للإيقاف المؤقت، `F` لملء الشاشة، `Esc` للخروج، والأرقام `1`–`5` للانتقال مباشرة إلى شريحة.
- عند تسجيل نتيجة ينتقل العرض إلى المجموعة المعنية، وتتحرك المراكز بحركة سلسة.
- عند **تأهل فريق رسمياً** أو **تتويج البطل** تظهر بطاقة احتفالية مع قصاصات ملونة وصوت.
- إذا كانت شاشة العرض على نفس الجهاز (نافذة ثانية)، تتحدّث تلقائياً فور إدخال النتائج.

### المتابعة العامة ورمز QR
- الرابط `#/live` واجهة للقراءة فقط بدون أدوات الإدارة، وتظهر مع رمز QR في الصفحة الرئيسية.
- ليعمل الرابط على هواتف الحضور يجب **تفعيل المزامنة** (انظر أدناه)، وأن يكون عنوان الموقع منشوراً على الإنترنت أو عنوان الشبكة المحلية. عنوان `localhost` لا يعمل على الهواتف.

## المزامنة المباشرة

المشروع مربوط بـ Firebase Realtime Database في مشروع `jakaro-league-hadiassayra`.

الرابط الرئيسي يفتح المتابعة العامة دون تسجيل دخول أو زر إدارة. لوحة الإدارة متاحة مباشرة على `/#/admin`، وصفحاتها كلها تتطلب حساب صاحب البطولة.

- افتح لوحة الإدارة وسجّل بحساب Google الخاص بصاحب البطولة. صلاحية التعديل محصورة بالحساب الموجود في `database.rules.json`.
- الأجهزة تتبع نفس البطولة `jakaro-league-2026`. عند أول تشغيل، تُرفع بيانات المتصفح المسجّل إذا لم تكن هناك بطولة محفوظة على الخادم. الأجهزة الجديدة تحمل النسخة المشتركة.
- صفحة المتابعة وشاشات المباريات والنتائج متاحة للقراءة دون تسجيل دخول وتتحدث مباشرة.
- إعدادات تطبيق Firebase العامة في `src/sync/defaultConfig.ts`، وقواعد الحماية في `database.rules.json`. لا تضع بيانات دخول Google أو مفاتيح حساب الخدمة في الكود.
- لنشر قواعد الحماية وتسجيل الدخول: `npx firebase-tools deploy --only database,auth`.
- انقل البيانات القديمة من متصفح آخر باستخدام تصدير واستعادة نسخة JSON إذا لزم.

## الهوية البصرية

- **الإعدادات ← الشعار والألوان**: ارفع شعارك (PNG أو SVG)، فتُستخرج ألوانه الأساسية تلقائياً ويُبنى منها الثيم بالكامل (اللون الأساسي والمميز والخلفية والنص). يمكن تعديل أي لون يدوياً مع معاينة مباشرة.
- يمكن أيضاً وضع ملف الشعار باسم `public/logo.png` ليصبح الشعار الافتراضي.
- يظهر الشعار في الرأس، وفي وضع العرض، وفي الصفحات المطبوعة.
- الوضع الداكن والفاتح من زر 🌙/☀️ في الأعلى.

## الطباعة والتصدير
- **الطباعة والتصدير**: اختر جداول المجموعات أو جدول المباريات أو الشجرة أو **أوراق تسجيل فارغة لكل طاولة**، ثم «طباعة / PDF».
- **تصدير Excel**: ملف فيه الترتيب وكل المباريات والأدوار الإقصائية والفرق.
- **نسخة احتياطية JSON** و**استعادة نسخة** من الإعدادات.

## ميزات أخرى
- **↶ تراجع** عن آخر إجراء (في الرأس، وفي الإشعار بعد كل نتيجة).
- **سجل النشاط**: كل نتيجة أُدخلت أو عُدّلت مع وقتها.
- **مؤقت المباراة**: «▶ بدء المباراة الآن» في نافذة النتيجة. يمكن تحديد مدة المباراة من الإعدادات (يتحول المؤقت إلى الأحمر عند تجاوزها).
- **ملف الفريق**: اللاعبان والنتائج ونقاط الفرق ومسار الفريق في الشجرة.
- **الإحصائيات**: أكبر فوز، والفرق التي لم تخسر، و«العودة بعد الخسارة» (فوز مباشرة بعد خسارة)، ومتوسط الكرات المتبقية، وأطول سلسلة انتصارات.
- **رمز PIN** لحماية لوحة الإدارة (حماية بسيطة داخل المتصفح).
- **المؤثرات الصوتية** (صوت الكرات ونغمة الفوز) مع زر كتم 🔇.

## للمطورين

- React 18 و Vite و TypeScript و Tailwind CSS 4، مع دعم RTL عبر `dir="rtl"` والخصائص المنطقية (`ms-`/`me-`/`start`/`end`).
- كل منطق البطولة دوال نقية في `src/lib` ولها اختبارات (`npm test`):

| الملف | الوظيفة |
|---|---|
| `roundRobin.ts` | توليد الجدول بطريقة الدائرة (circle method) |
| `standings.ts` | النقاط ونقاط الفرق وكسر التعادل |
| `knockout.ts` | التوزيع المتقاطع وتقدّم الفائزين في الشجرة |
| `qualification.ts` | حساب التأهل والخروج رياضياً |
| `stats.ts` | الإحصائيات |
| `importTeams.ts` | قراءة ملفات الفرق |
| `colors.ts` | استخراج ألوان الشعار وبناء الثيم |
| `sample.ts` | البيانات التجريبية |

- الحالة في `src/store` (zustand مع localStorage)، والمزامنة الاختيارية في `src/sync`.
