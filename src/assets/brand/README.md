# FICTION logo assets

Prepared from the two logo references supplied by the site owner, using the built-in image_gen tool.

- `fiction-badge.png`: blue-filled badge, used on light surfaces and printed pages, with a blue backing to keep the white tagline readable.
- `fiction-outline.png`: yellow lettering and white outline, used on dark surfaces and the blue presentation header.
- The original references contained an opaque gray checkerboard; the supplied assets use alpha transparency.

## Final prompts

### Blue badge

Create a production-clean faithful reconstruction of the supplied FICTION BOARD GAMES CAFE logo as a crisp flat vector-style bitmap with TRUE transparent alpha background. Exact branding: bright yellow heavy uppercase FICTION inside a deep royal-blue long horizontal badge; thick white continuous chamfered rounded rectangular outline. Below badge, clean solid white uppercase bold BOARD GAMES CAFE, centered. Match the reference letterforms, layout, proportions and colors very closely. All edges must be smooth and clean, all letter interiors fully filled with their original solid colors. Remove all gray checkerboard, all stray white pixels, all scratches, fringe, noise and debris. NO texture, no outlines around individual letters, no shadows, no checkerboard background. Wide horizontal logo about 3:1 aspect ratio, tightly fitted with 3% transparent margins. This is the same established logo, do not invent a different design.

### Transparent outline

Create a production-clean faithful reconstruction of the supplied FICTION BOARD GAMES CAFE logo as a crisp flat vector-style bitmap with TRUE transparent alpha background. Exact branding: bright yellow heavy uppercase FICTION within a thick solid-white chamfered rounded rectangular outline; the interior of the badge is transparent, absolutely NO blue fill. Below badge clean solid-white uppercase bold BOARD GAMES CAFE centered. Match reference letterforms, layout, proportions and colors closely. All edges smooth and clean, all yellow and white letters solid-filled and intact. Remove all gray checkerboard, stray white pixels, scratches, fringe, noise and debris. NO texture, no shadows, no checkerboard. Wide horizontal logo about 3:1 aspect ratio, fitted with 3% transparent margins. Same established logo, do not invent a different design.
